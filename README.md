## ⚡ Portfolio Features

- **Blueprint Grid Aesthetic**: Dual-scale technical graph background (64px major + 16px minor grid) with light architectural drafting theme and dark cyber mode.
- **Interactive Architecture CLI Terminal**: Built-in simulated shell supporting commands like system --audit-mode, whoami, cat architecture.md, systemctl status metrics, and dispatch contact --email.
- **Audited Project Showcase**: Filterable showcase categorizing microservices, enterprise Onion APIs, IoT telemetry, and web apps with direct GitHub repository links.
- **Mobile First**: Full mobile navigation drawer and floating quick-action bottom dock (Projects, CLI, Email, Call, Theme).
- **Zero Heavy Framework Bloat**: Pure vanilla CSS design system with custom CSS variables, glassmorphic cards, and zero runtime CSS-in-JS overhead.
